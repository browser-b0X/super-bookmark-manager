Source setup · PowerShell 
# Get the source
git clone https://github.com/browser-b0X/super-bookmark-manager.git
cd super-bookmark-manager

# Install dependencies
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r packaging/requirements-build.txt
npm.cmd --prefix frontend ci

# Build and run locally
npm.cmd --prefix frontend run build
.\.venv\Scripts\python.exe run.py --serve-only
Open http://127.0.0.1:5001 in your browser.
Keep the local server running while using the app.

Source setup requires Git, Python 3.12, and Node/npm. Verified with Python 3.12.10 and Node 24.19.0. Full build instructions ↗
