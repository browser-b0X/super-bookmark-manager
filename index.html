Optional AI, free keys

Tidy messy captions into clean titles

Add a free key and the app suggests a shelf, a few tags, a clean title and a one-line summary. You review every suggestion before it is saved; your own edits are never overwritten. Without a key, local keyword rules sort your links.

Your data, your machine

Local first, with backups you own

Links and notes live in a SQLite file on your PC; keys stay in your user profile. Previews contact the saved sites, Telegram actions contact Telegram, and AI is used only if you add a key. Privacy details

From scattered to sorted in three steps

  1. Import what you already have

    Drop a browser export, a Telegram JSON file or a WhatsApp chat export into Settings. The format is detected and you see a preview before anything is saved.

  2. Sort the strip

    Keep, later or archive each new link right in the feed — or open it to read first. Folders can become shelves on import.

  3. Rediscover

    Search with filters like site:, #tag and is:later, save views, and let old favourites resurface when the strip is empty.

Install in a minute

  1. Download the latest release — the Windows installer and its checksum are on GitHub.
  2. Install and open it from the Start Menu. No Python or Node needed; it opens in your browser at 127.0.0.1:5001.
  3. Bring your links in Settings. Telegram uses your own API keys; AI keys are optional.
Get the latest release

The installer is unsigned and Windows SmartScreen may warn you. Check its SHA-256 against the published checksum before running it.

Build from source · PowerShell
git clone https://github.com/browser-b0X/super-bookmark-manager.git
cd super-bookmark-manager
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r packaging/requirements-build.txt
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
.\.venv\Scripts\python.exe run.py --serve-only
Then open http://127.0.0.1:5001 and keep the server window running.
