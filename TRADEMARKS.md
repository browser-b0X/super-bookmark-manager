# SuperBookmarks name and logo

The code of SuperBookmarks is open source under the [MIT License](LICENSE): you may use,
copy, change and share it. The MIT License covers the code only. The name **SuperBookmarks**
(and the earlier name **Super Bookmark Manager**) and the jar logo are not part of that
license. They tell people they have the official app, from browser-b0X.

## Fine without asking

- Saying your project is "based on SuperBookmarks" or "a fork of SuperBookmarks", with a link
  to this repository.
- Using the name to talk about the app: reviews, articles, videos, tutorials, comparisons.
- Packaging an unchanged official release under its own name (a package manager listing, say).

## Not without permission

- Releasing a changed version under the SuperBookmarks name, or with the jar logo or the app
  icon. A fork needs its own name and icon.
- Using the name or logo in a way that suggests your project, product or service is official,
  endorsed or made by browser-b0X.
- Using the name or logo for a paid product or service, an app store listing, or a domain name.

## Official downloads

The official builds are the installers on this repository's
[Releases page](https://github.com/browser-b0X/super-bookmark-manager/releases) and the
WinGet package `browser-b0X.SuperBookmarkManager` (once it is listed). Copies from anywhere
else are not checked by the author.
